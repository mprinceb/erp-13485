# ERP, QMS, And HRMS Architecture Reference

This folder contains the cross-app reference architecture and research notes for the local bench across:

- `erpnext`
- `qms`
- `hrms`
- small new bridge or exception modules where required

Use this folder as reference material for writing or extending SOPs with ERP/qms/HRMS workflows.

## Current Verdict

The research is complete enough to present:

- the current approved SOP baseline
- the system architecture target state
- the main gaps between the two
- the implementation sequence needed to close those gaps

The research is not complete enough to claim:

- the full ISO 13485 operating model is already fully documented and approved
- every major domain is already implemented, approved, trained, and operating in-system
- the proposed bridge and new modules are already implemented or fully design-closed
